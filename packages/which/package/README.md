# `@ai-ecoverse/wasm-which`

[GNU which](https://www.gnu.org/software/which/) 2.23 for
[slicc](https://github.com/ai-ecoverse/slicc)'s wasm realm.

```bash
pnpm add -g @ai-ecoverse/wasm-which
which ls
```

Requires a slicc-kernel that installs `pnpm add -g` packages onto PATH
(see ai-ecoverse/slicc-kernel#88).
