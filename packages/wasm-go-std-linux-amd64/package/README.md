# `@ai-ecoverse/wasm-go-std-linux-amd64`

Optional Go 1.27 std export archives for `linux/amd64` (cgo-free
cross-compile from the wasip1 tools).

```text
goroot/pkg/linux_amd64/<import path>.a
```

Declares `slicc.go.std` only; driver unions with wasip1 std for the same
`go` version.
