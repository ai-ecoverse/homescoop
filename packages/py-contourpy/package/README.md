# `@ai-ecoverse/py-contourpy`

contourpy 1.4.0 for slicc WASIX CPython 3.14 (`cpython-314-wasm32-wasix`).

Since 1.4.0-8 it is built from the sdist in homescoop's CI (homescoop#211): `_contourpy` is compiled with wasixcc++ and pybind11 3.0.1 against the C++ runtime that `@ai-ecoverse/wasix-python` exports. It takes wasix-python `>=3.14.2-27 <3.14.3` and py-numpy `>=2.3.2-10 <2.3.3`.
